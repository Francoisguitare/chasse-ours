# Chassé d'Ours

Jeu 3D dans le navigateur : infiltration, parkour et chassés monumentaux dans les ruines de Val-Perdu.

**Jouer :** https://francoisguitare.github.io/chasse-ours/

- **Histoire** en cinq chapitres : retrouver la trace d'Anselme, voler le miel du Baron, le faire s'assommer contre un mur.
- **Furtivité** : hautes herbes, murs et perchoirs cachent des ours.
- **Parkour** : on grimpe tout seul en fonçant sur un obstacle, on saute d'un toit à l'autre en sprint, chassé plongeant depuis un perchoir.
- **Le coup de pied évolue** : onde lourde (niveau 3), mur du son (5), météore (8), mise en orbite (12).
- **Duel à deux** : « Créer un duel à deux » sur l'écran-titre, puis envoyer le lien. Les navigateurs se relient en direct (WebRTC via PeerJS) ; ça marche mieux en wifi.

Commandes : ZQSD ou flèches, Maj pour sprinter, C pour s'accroupir, Espace ou clic pour armer et frapper, clic droit ou A/E pour la caméra, F pour le plein écran. Sur téléphone : pouce gauche pour marcher, pouce droit pour la caméra, boutons Chassé et Accroupi.

Aucune installation : des fichiers statiques, three.js et PeerJS chargés depuis cdnjs.
